# models/

The `*.onnx` files are git-ignored: they are large binaries and are regenerated by scripts. Each model has a sidecar
`<name>.json`, which `metagross.autonomy.perception.semantics.Segmenter` reads to get the model kind, input size and
normalisation. The sidecar also records the classes, training data, metrics, export check and licence.

| File | What | How it is produced | Use |
|---|---|---|---|
| `lraspp_offroad5_robust.onnx` | LR-ASPP MobileNetV3, OFFROAD5, ROBUST aug, 320x416 | `aws/setup_and_train.sh` then `aws/fetch_results.sh` | **Deploy model**, first choice |
| `lraspp_offroad5_clean.onnx` | Same, CLEAN aug | Same | Ablation / fallback |
| `lraspp_smoke.onnx` | LR-ASPP after a 300-iteration CPU smoke run on 800 RUGD-5L images, 256x320 | `train_seg` + `export_onnx` (commands in `docs/MODEL_CARD.md`) | **SMOKE**: lets the node run semantics before the GPU model exists. Not a trained model |
| `segformer_b0_ade.onnx` | SegFormer-B0 ADE20K (Xenova export), 150 classes mapped to 5, dynamic input (sidecar sets 320x416) | `python scripts/download_seg_data.py --models-only` | Zero-shot research baseline. NVIDIA non-commercial licence: **never deploy** |

The model is selected in this order:
1. `config["seg_model_path"]`, if set;
2. otherwise the first file that exists in `DEFAULT_MODEL_CANDIDATES`: robust, then clean, then smoke. The SegFormer
   baseline is never chosen automatically; it runs only when named in `seg_model_path`.

Thread count: `config["seg_threads"]` (default 2).

Quick check:

```python
from metagross.autonomy.perception.semantics import Segmenter
seg = Segmenter.from_config({})          # picks the best available model
ids, entropy = seg(rgb)                  # (H, W) uint8 class ids, (H, W) float32 in [0, 1]
```
